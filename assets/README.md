All images were created by DALL-E using ChatGPT and post-processed with GIMP.

Processing was mostly limited to a threshold operation and saving off as WEBP to reduce file sizes.

## Item and Treasure sprites
Item and treasure images were created with the same flow, but more effort was required in post-processing to add an acceptable transparent background since DALL-E was unreliable with this important detail.

This was accomplished by adding any needed background colour (black) areas to the outline manually, so the inside shape was contiguous enough for a bucket fill operation to work. The outside of the image was then bucket filled to any other colour, then colours>colour to Alpha was used to convert this outer coloured area to tranparent. Finally the image was cropped to size.
